## 引退する2つの名車と「日本初のクラフトビール」

<figure class="embed embed--image"><img src="https://prcdn.freetls.fastly.net/release_image/95753/2480/95753-2480-b3722fcf8f529ddf16896164453fc956-1280x720.png?width=1200&amp;height=900" alt="500系新幹線と923形ドクターイエローの引退を記念した「THE LAST RUN BEER」の商品イメージ" loading="lazy" /><figcaption>500系新幹線と923形ドクターイエローの引退を記念した「THE LAST RUN BEER」の商品イメージ — 画像提供: PR TIMES（西日本旅客鉄道）（プレスリリースより）</figcaption></figure>

西日本旅客鉄道（JR西日本）グループの商社であるジェイアール西日本商事と、新潟県新潟市の醸造所エチゴビールが、缶ビール「THE LAST RUN BEER」を2026年11月27日に発売します。記念するのは、2027年1月に引退する予定の2つの新幹線車両です。1つは日本で初めて時速300kmでの営業運転を実現した「500系新幹線」。もう1つは「923形ドクターイエロー」で、線路や設備の状態を測りながら走る黄色い点検用車両として、長年新幹線の安全を支えてきました。どちらも鉄道ファンだけでなく、家族連れにも人気の車両です。エチゴビールは「日本初のクラフトビール」を生んだ醸造所として知られ、JR西日本グループとの共同企画は今回が初めてです。缶には両車両の公式引退ポスターとJR西日本グループのロゴがあしらわれ、飲んだ後も記念に取っておきたくなるデザインになっています。

## チェコ産ホップが香るクラシックなピルスナー

<figure class="embed embed--image"><img src="https://images.pexels.com/photos/7016487/pexels-photo-7016487.jpeg?auto=compress&amp;cs=tinysrgb&amp;dpr=2&amp;h=650&amp;w=940" alt="黄金色に澄んだピルスナー（イメージ）" loading="lazy" /><figcaption>黄金色に澄んだピルスナー（イメージ） — 写真: Darlene Alderson（Pexels）</figcaption></figure>

中身はピルスナーです。ピルスナーは淡い金色で、すっきりした飲み口のラガービールのスタイルで、チェコのボヘミア地方で生まれました。このビールは原料に麦芽だけを使い、ホップにはチェコのザーツ地方（英語・ドイツ語圏では「Saaz」）産のアロマホップを使っています。日本の大手ビールには米やコーンを副原料に使うものも多いため、「麦芽100％」は品質へのこだわりを示す表示としてよく使われます。華やかなホップの香りと、さわやかな苦みが特徴だといいます。アルコール度数は5％、容量は350ml、日本国内での価格は税込374円です。

## ヨーロッパの読者へ：どう楽しむか

<figure class="embed embed--image"><img src="https://images.pexels.com/photos/31985625/pexels-photo-31985625.jpeg?auto=compress&amp;cs=tinysrgb&amp;dpr=2&amp;h=650&amp;w=940" alt="摘み取られたばかりのアロマホップの毬花（イメージ）" loading="lazy" /><figcaption>摘み取られたばかりのアロマホップの毬花（イメージ） — 写真: Ben Young（Pexels）</figcaption></figure>

数量限定で、販売は京都・新大阪・大阪・博多などJR西日本エリアの主要駅の土産売り場と、JR西日本の公式オンラインショップに限られます。現時点で海外での販売は発表されていません。それでもこの商品には、ヨーロッパの読者が注目したい点が2つあります。1つは、日本のクラフトビールの草分けであるエチゴビールが、ヨーロッパのホップでチェコの伝統的なスタイルに取り組んでいることです。手元にあるボヘミア産のピルスナーを飲みながら、日本の醸造所が同じ原料で目指す「軽く、香り高く、キレのある」味わいを想像してみるのも楽しいでしょう。もう1つは、鉄道とお酒を組み合わせる日本ならではのコレクター文化です。最新情報は、ジェイアール西日本商事が運営する公式Instagram（@trainbox_jrwt）で発信される予定です。
